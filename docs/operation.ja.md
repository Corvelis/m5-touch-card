# 操作ガイド

[日本語](operation.ja.md) · [English](operation.en.md) · [インストール](install.ja.md)

## 名刺を設定する

1. 本体で「メニュー → 設定 → スマホから更新」を開きます。
2. スマホの「名刺」で名前を入力します。アイコン・アカウント・メール・QR用URL・一言は任意です。
3. 「変更を保存」→「NFCで名刺を更新」を選び、本体のNFC部分にスマホを合わせます。
4. 本体の保存完了まで待ちます。送信が100%になっても、保存確認が終わるまで離さないでください。
5. スマホ上部の時計ボタンから日時も送れます。本体の待機画面は同じです。

待機画面がタイムアウトした場合は、もう一度「スマホから更新」を開きます。
スマホの「変更を保存」はスマホ内の保存です。本体へ反映するにはNFC更新が必要です。

### 更新する内容を選ぶ

| スマホの操作 | 本体で変わるもの |
| --- | --- |
| NFCで名刺を更新 | 自分の名刺本文とアイコン |
| 追加メニュー → 内容だけ更新 | 本文のみ |
| 追加メニュー → アイコンだけ更新 | 同一プロフィールのアイコンのみ |
| アイコンを初期画像に戻す | スマホ側でリセット。NFC更新で本体へ反映 |
| 画像 → 日時・カレンダー | 日時ホーム用の写真 |
| 画像 → 全画面 | 全画面写真 |
| 上部の時計ボタン | 日時・UTCオフセット |

本体で項目別の受信先を選ぶ必要はありません。名刺アイコンと2種類のホーム写真は互いに上書きしません。
画像の「画像を送る端末」を変えると、その用途の元画像から新しい寸法へ自動で中央切り抜きします。
構図は「保存した元画像から切り抜き直す」で調整できます。

送信待ちはスマホを再起動しても保持します。新しい内容に切り替えるときは、送信待ちの置き換えを確認してください。
アプリを削除すると下書き・元画像・プロフィールIDも失われ、別の名刺として扱われる場合があります。

## 名刺を交換する

### お互いの名刺を交換

1. 両方の本体で「名刺交換 → 交換」を開きます。
2. 一方を「先に渡す」、もう一方を「先に受け取る」にします。
3. NFC部分を近づけます。「1/2」の転送後、自動で役割が入れ替わります。
4. 「2/2」が完了するまで離さないでください。完了すると、両方の画面に相手の名刺を表示します。

受け取った名刺は名刺帳にも保存します。途中でキャンセルしたり2枚目の転送に失敗したりしても、既に保存した1枚目は残ります。

### 片方だけ渡す

送信側で「渡す」、受信側で「受け取る」を選んでタッチします。「交換」と片方向モードは組み合わせられません。
両方の本体に互換性のあるM5 Touch Cardが必要です。

### 画像を軽くする

スマホの「名刺 → 交換用アイコン → 交換用を160pxにする」を選び、NFCで本体を更新します。
相手に渡す画像だけを小さくし、元画像・自分の本体表示用画像・ホーム写真は保持します。
交換にかかる時間は画像の容量、通信状態、保存先によって変わります。

## 名刺帳・ストレージ

- 「メニュー → 名刺帳」で受信名刺を開きます。下部の左で名前順／最新順、中央と右でページを切り替えます。
- 行をタップすると名刺を表示します。「全文を読む」「QRを表示」で詳細を確認できます。名刺帳から戻るときは右上の「戻る」を押します。
- 名前順は文字コード順で、漢字の読み順ではありません。
- 「この名刺を削除」で対象を確認して削除します。削除後は通常操作では元に戻せません。接続していないSD上のコピーは削除されません。
- 「設定 → ストレージ」で本体・SDの使用量、空き容量、名刺件数を確認できます。保存件数は実容量と作業用の空き領域で決まります。
- 保存先は「自動（SD優先）」または「本体」。自動では、保存開始時にSDを使えなければ本体を使います。転送中のSD抜去や書き込み失敗で別媒体へ書き継ぐことはありません。
- SD上だけの名刺は、SDがない間は表示されません。再挿入すると一覧へ戻ります。本体とSDに同じIDがある場合は最新版を表示します。
- SDを抜くときは、ストレージ画面の「取り外す」を選び、「取り外し可能」を確認します。再開は「再読み込み」を使います。

microSDなしでも使用できます。古い名刺の自動削除やSD全体の自動フォーマットはしません。
SDは専用の `/tc` フォルダーだけを管理します。大切なデータはPCなどへバックアップしてください。

### 内部ストレージの初期化

内部ストレージを使えない場合は「設定 → ストレージ → 本体」で状態を確認してください。
「初期化の確認 → 消去して初期化」は**内部の名刺・画像を削除する操作**です。SDは消しません。
正常な更新で初期化は不要です。接続や保存先を確認し、必要なデータを保護してから実行してください。

## ホーム・デザイン

- 「メニュー → ホーム表示」で「名刺」「画像＋日時・カレンダー」「全画面写真」を選びます。
- 名刺の左下は「名刺交換」、右下は「メニュー」。本文をタップすると全文・QRの操作を開きます。
- 日時ホームでは大きな時計、写真、週間カレンダーを表示し、タップすると月間カレンダーを開きます。
- 全画面写真には時刻やボタンを重ねません。タップするとメニューを開きます。
- 「設定 → 名刺デザイン」でタイポグラフィ／コントラスト／シンプルを選べます。
- PaperMonoは「設定 → 名刺の向き」で縦向き／横向きを選べます。名刺とQR拡大に適用し、設定画面や写真の向きは変えません。
- プレビューの右下は「メニュー」、それ以外の部分をタップするとホームへ戻ります。メニュー下部にも「ホームへ戻る」があります。

長い項目は名刺上で省略するため、「全文を読む」で確認してください。デザイン・向きは再起動後も保持します。

## ボタン・言語・電源

| 操作 | PaperMono | StackChan |
| --- | --- | --- |
| A短押し | 行を選択 | 行を選択 |
| A長押し | ホーム／メニューへ戻る。NFC中はキャンセル | 同左 |
| B短押し | ライトをオン・オフ | 決定。NFC中はキャンセル |
| 電源短押し | リセットを無効化 | 画面をオン・オフ |

本体の言語は「設定 → その他 → 言語 / Language」、スマホは上部の地球メニューで選びます。
それぞれ独立して保存され、名刺本文を翻訳・変更することはありません。スマホのiボタンはライセンスを開きます。
本体の電源オフ・再起動は「設定 → その他 → 電源」から実行できます。名刺・設定は消去しません。

### PaperMonoの消灯・省電力

消灯中はタッチとAボタンをロックし、名刺・日時ホームの下部ボタンを隠します。Bで再点灯してください。
再点灯時は下部ボタンだけを部分更新し、操作できる状態に戻ります。

- NFC待機・通信・保存・描画などがないとき、CPUをライトスリープにします。
- 時計の分の切り替わりに起き、時刻・電池を部分更新して再びスリープします。ライトは点きません。
- 毎時00分に、残像を抑える全画面更新を行います。NFC処理などの最中は終了後へ保留します。時計未設定時と全画面写真は対象外です。
- 日付・カレンダーの変更は再点灯後に反映します。SDの挿抜検知は次の起床まで約1分かかることがあります。
- USB接続中もスリープします。書き込みや診断の前にBで点灯してください。

電子ペーパーは高速更新時に残像が残る場合があります。起動時と毎時の全画面更新では画面が点滅します。
電源ボタンの短押しリセット・ダブルクリック電源オフは無効化し、側面の赤LEDはアプリ起動時に消灯します。

### StackChanの消灯

電源ボタン短押しで画面を消灯し、もう一度押すと点灯します。消灯中はタッチ・A・Bを受け付けません。
NFC・保存・時計は動作を続けます。画面の消灯は本体のスリープではなく、転送完了時も自動では点灯しません。
ハードウェアの電源長押し動作は維持します。
