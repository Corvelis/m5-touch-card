# 操作ガイド

## 初回セットアップ

[インストール手順](install.ja.md)に従ってリリースを導入するか、対象機種向けにソースをビルドして使用します。
既存製品のデータ領域とは別形式です。旧端末への書き込み・初期化前にはバックアップしてください。
ビルドだけでは書き込まれません。書き込み時には機種とポートを確認してください。

内部データ領域が未初期化の場合は「メニュー → 設定 → ストレージ → 本体」から
「初期化の確認」を開けます。明示的に「消去して初期化」を押したときだけ内部の名刺・画像を
消去します。正常にマウントできる領域を自動的に初期化する機能はありません。SDは消去しません。

1. 本体は「設定 → スマホから更新」。項目別の受信先選択は不要です。
2. スマホは「名刺」で名前を入力。アイコン・連絡先・一言は必要な場合だけ設定。
3. 「変更を保存」で下書き保存。「NFCで名刺を更新」で本体へ送り、保存完了を待つ。
4. 時計はアプリ上部の時計アイコン。本体の待機画面は同じです。
5. 待機は無通信で60秒、転送の無通信で120秒まで。終了したらもう一度待機を開きます。

同じスマホのプロフィールIDを維持したまま更新世代を進めます。アプリデータを削除すると
新しいIDになります。別人の名刺受信で自分の名刺が書き換わることはありません。

## 本体のホームと名刺

- 名刺ホーム下部の左「名刺交換」、右「メニュー」。名刺本文をタップすると全文・QRの操作。
  初期の未設定状態ではタップでメニューへ進みます。
- 「メニュー → ホーム表示」で名刺 / 画像＋日時・カレンダー / 全画面写真を選択。
- 日時ホームでは時刻を大きく、カレンダーを小さく表示。タップで月間、右下からメニュー。
  PaperMonoは上から128pxの時刻・日付・正方形写真・曜日付き週間表示。
  月間表示は月を大きく、今日を黒丸で示します。通常の毎分更新は時刻部分のみで、写真の内容は変更しません。
  日付が変わったときは週間・月間表示も更新します。既存の保存画像はそのまま使えます。
- 全画面写真は重ねる表示なし。どこかをタップするとメニュー。
- 「設定 → 名刺デザイン」でタイポグラフィ / コントラスト / シンプルを選ぶとプレビュー。
  左側タップで元のホーム、右下の「メニュー」でメニューへ移動します。ホームの種類は変更しません。
  名刺ホーム・受信名刺・プレビューの右下は、機種や縦横・デザインに関係なく「メニュー」に統一しています。
- PaperMonoのみ「設定 → 名刺の向き」で縦向き / 横向きを選べます。向きとデザインは独立し、
  縦横どちらでも3種類を選べます。選択後はプレビューを表示し、再起動後も設定を保持します。
  初期値は従来どおり縦向きです。StackChanには向きの設定を表示しません。
- 横向きは自分の名刺、受信した名刺の表示、プレビュー、QR拡大に適用します。
  左上の時刻・右上の電池残量を維持し、QRをタップすると拡大します。
  名刺帳の一覧、設定・メニュー、NFC待機、全文表示、画像ホームは従来の向きに戻ります。
  画像データ・NFCパケットはこの本体設定では変更しません。
- 名刺帳から開く名刺は長い項目を省略表示します。「全文を読む」でページごとに閲覧。
  Paper Monoは名刺内にもQR、StackChanは詳細の「QRを表示」で拡大して表示します。

通常操作はタッチが基本です。メニュー下部の「ホームへ戻る」からホームへ戻れます。
A長押しでホーム/メニュー（NFC中はキャンセル）、A短押しで行選択。
PaperMonoのB短押しはライトをオン・オフします。消灯中はタッチ・A短押し/長押しを無効化し、
Bだけで再点灯できます。再点灯時は下部の操作表示だけを高速部分更新で戻し、
残像消去用の全画面リフレッシュは行いません。
消灯時は下部の操作表示と区切り線だけを消し、名刺・時刻・電池表示は残します。
縦向き・横向きの両方で対応し、再点灯時に操作表示も戻します。
画像＋日時ホームでも操作表示を隠します。全画面写真の下端は消去しません。
更新完了後、押していた指・ボタンを離してから通常操作に戻ります。
消灯中、NFC待機・通信・保存・名刺帳走査・画面描画が終わっている場合はCPUをライトスリープさせます。
次の分の境界で一時的に起き、時計・電池を更新したら再びスリープします。毎分の起床ではライトを点けません。
BボタンはGPIOによる復帰に使い、押すと点灯して操作を再開します。復帰に使ったボタンを離す操作は消灯に使いません。
タッチ・Aボタンはスリープの解除に使いません。SD挿抜の確認はスリープから復帰した時に行うため、消灯中は最大約1分遅れます。
画面の状態とメモリーを保持するCPUライトスリープであり、再起動を伴うディープスリープではありません。
毎分の休止・復帰では画面側の電源・省電力モードを切り替えません。描画ドライバーの差分情報を維持し、
意図しない毎分の全画面更新を防ぎます。画面制御回路の追加休止は行わず、CPUの休止を維持します。
NFC待機・通信・保存中はスリープを保留し、点灯操作で通信をキャンセルしません。
時計と電池表示は消灯中も通常は毎分部分更新します（全画面写真には表示を追加しません）。
PaperMonoは毎時00分（9:00、10:00など）だけ、残像消去用の全画面リフレッシュを1回行います。
点灯・消灯の両方で適用し、ライトの状態や写真・名刺・非表示の操作欄はそのまま維持します。この時だけ全画面の点滅を伴います。
時計・電池と、点灯中の日付変更が同時にあっても、全体更新は1回にまとめます。
NFC待機・通信・保存・名刺帳走査・描画中は全体更新を保留し、終了後に1回だけ行います。保留分を連続で実行しません。
時計未設定時と時計表示のない全画面写真は対象外です。00分に起動した場合は初回の全体描画を兼用します。
通常の部分更新では写真・名刺本体・非表示の操作欄は変更しません。描画中は更新を短く保留して再試行します。
消灯中の日付・カレンダー更新は再点灯後の定期更新まで保留し、その部分だけ描き直します。
電子ペーパー固有の軽い残像や局所的な点滅は残る場合があります。
スリープの設定・移行に失敗した場合は起動状態を維持し、5秒以上間隔を空けて再試行します。
`[tc.power.sleep]`に起床理由（minute/button）またはエラーを記録します。USB接続中もスリープするため、
スリープ中のUSBシリアル応答は保証しません。Bボタンで復帰してから診断してください。
毎分の部分更新修正と毎時の残像消去の実機表示・消費電流は未確認です。CPUを休止する実装で、
周辺機器の電源レールやSD電源を一括で切断するものではありません。
StackChanのB短押しは決定（NFC中はキャンセル）で、従来どおりです。

### 言語と電源

- PaperMono側面の赤LEDは、このアプリでは起動時に消灯します。電源管理チップの初期点灯であり、充電中表示としては使用していません。充電・画面ライトの設定は変更しません。ファームウェア起動前やダウンロードモードの点灯・点滅は対象外です。
- 本体は「設定 → その他 → 言語 / Language」で日本語 / Englishを選択。すぐ反映され、再起動後も保持します。
  保存に失敗した場合は言語を変えずエラーを表示します。名刺の名前や内容は翻訳・変更しません。
- スマホは上部の地球アイコンを押し、下に開くメニューから日本語 / Englishを選びます。旧版のスマホ言語追従設定は日本語へ移行します。
  本体とスマホの言語は独立です。NFC更新時に本体の言語を勝手に変えません。
- PaperMonoは起動時に電源短押しリセットとダブルクリック電源オフを無効化します。
  設定失敗時は警告します。電源ボタン長押しのダウンロードモードは維持します。
- StackChanは電源短押しで画面だけ消灯し、もう一度押すと直前の明るさへ復帰。
  消灯中はタッチ・A/Bを受け付けません。復帰時の押しっぱなしも無視します。
  NFC送受信・保存・時計は動作を続け、完了しても自動で画面を点灯しません。
  これは本体スリープではありません。ハードウェアの長押し電源オフは無効化しません。
- 本体の「設定 → その他 → 電源」で電源オフ / 再起動を選び、右下「実行」で確定します。
  名刺や設定の消去は行いません。確認画面の左下でキャンセルできます。
- 初期言語は指定なしなら日本語。英語ビルドでも保存済み言語は優先されます。手順はREADMEを参照。

## スマホからの用途別更新

| スマホ操作 | 本体で変わるもの |
| --- | --- |
| NFCで名刺を更新 | 自分の名刺本文とアイコン |
| 名刺タブの追加メニュー → 内容だけ更新 | 本文のみ。アイコンは維持 |
| 同 → アイコンだけ更新 | 同一プロフィールのアイコンのみ |
| 同 → アイコンを初期画像に戻す | まず下書きをリセット。NFC更新で本体へ反映 |
| 画像 → 日時・カレンダー → この画像をNFCで送る | 日時ホーム用の画像だけ |
| 画像 → 全画面 → この画像をNFCで送る | 全画面写真だけ |
| 上部の時計ボタン | UTC時刻とUTCオフセットだけ |

画像タブの「画像を送る端末」を変更すると、表示中の用途の画像を元画像から中央で
自動切り抜きし、新しい端末に合うサイズで保存します。元画像、名刺アイコン、もう一方の
用途の画像は保持します。構図は手動で切り抜き直せます。用途を切り替えると、その画像に
保存された端末を表示します。変換や保存に失敗した場合は、元の画像と端末選択に戻ります。

一度保存した送信待ちは、別の画像操作をしても勝手に置き換わりません。
上部の「送信待ち」から同じ内容で再開。新しく送信する内容へ変更するときは確認を表示します。
途中までのRFバッファは本体RAM上なので、再起動・待機を閉じた場合は最初から送り直します。
本体に同じ内容が保存済みなら、再送しても別の名刺を増やしません。

## 名刺を渡す・受け取る

双方でM5 Touch Cardを使用します。Paper Mono同士、StackChan同士、異なる機種でも同じ手順です。

1. 渡す側: 「メニュー → 名刺交換 → 渡す」。SDがなくても自分の名刺を送信できます。
2. 受ける側: 「メニュー → 名刺交換 → 受け取る」。表示された保存先方針を確認。
3. NFC部を近づけて保持。保存確認後、受けた側は受信名刺を表示します。
4. この手順は片方向です。お互いの名刺を自動で渡したい場合は、下記の「交換」を使用します。

本体の待機中はRF応答を優先し、電子ペーパーを頻繁に更新しません。
送信に失敗したら内容を保持したまま待機を開き直して再試行してください。

### 画像付きで2秒前後を目指す高速交換

#### 交換

両方を相互交換対応の本体ファームウェアに更新してください。スマホアプリの変更は不要です。

1. 両方で「名刺交換 → 交換」を開きます。自分の名刺が未設定なら先にスマホから設定します。
2. 一方は「先に渡す」、もう一方は「先に受け取る」を選び、NFC部分を近づけます。
3. 「1/2」で最初の名刺を保存し、自動で役割を切り替えて「2/2」で逆方向に渡します。
4. 2枚目の交換が完了するまで離さないでください。完了後は両方の画面に受け取った相手の名刺を表示します。名刺帳にも保存されます。

途中キャンセル・片方の保存失敗では、既に保存した名刺を削除しません。
2枚目の失敗時は1枚目が完了した旨を表示します。やり直す場合は両方で同じ手順を開始してください。
片方向の「渡す」「受け取る」も従来どおり利用できます。相互交換と片方向モードは混在できません。
相互交換の所要時間は2回分の転送・保存と役割切り替えを含み、全体2秒を保証するものではありません。

#### 画像の軽量化

これは目標であり、実機で2秒以内を確認済みという意味ではありません。
接続・保存確認・画面更新を含めた所要時間は画像、SD、通信状態で変わります。

1. 両方の本体を高速交換対応ファームウェアに更新し、スマホアプリも更新します。
2. 新しくアイコンを選ぶと、元画像・本体表示用JPEGに加えて交換用JPEGを作ります。
   以前に保存したアイコンは「名刺 → 交換用アイコン → 交換用を160pxにする」を選びます。
   既存の256px交換画像も読み込めます。縮小時は名刺の更新番号が進みます。
3. 同じ欄で「本体表示」と「相手に渡す画像」を比較できます。交換用だけ160×160に縮小し、
   6 KiB程度を目標に圧縮します。JPEG品質55を下限とし、複雑な写真は目標を超える場合があります。
   本体表示用256×256・元画像・ホーム写真には変更を加えません。
4. 「NFCで名刺を更新」で本体へ送ってください。スマホで軽量化しただけでは本体は変わりません。
   古い送信待ちは自動変更しないので、残っている場合は新しい内容への置き換えを確認します。
5. 以後の本体同士の交換では軽い画像を使います。本体の自分の名刺の元のJPEGと
   ホーム画像は変更しません。受信者の名刺には交換用JPEGを保存します。

新しい本体同士ではJPEGをBase64にせず送り、最大240バイト単位で往復します。
通信不良時は128/64バイトへ戻し、同じ転送を継続します。相手が古い場合は従来のJSON方式。
軽量化画像は相手の対応有無では変えないため、同じ更新世代の名刺内容は一定です。
送信者は保存確認後にFINISHを送り、完了後の4秒待ちを省略します。受信者もFINISHに
応答した後に表示へ移ります。FINISHが届かない場合やスマホ更新時は従来の受信猶予を残します。

付属画像の圧縮テストでは本体用15,212バイト→交換用5,728バイトでした（160px）。
これは容量の測定で、NFC速度の実測ではありません。iPhoneから本体を更新する前は以前の画像を送信します。
`node scripts/estimate_card_transfer.mjs` は転送下限の概算を再現します。
本文512バイト想定で、交換用8 KBは約0.87秒、10 KBは約1.07秒に接続・I2C処理・保存等が加わります。

実機での確認手順:

- 片方向の1枚で、接触から双方の完了表示までを動画等で測定。逆方向は別に測定。
- 本体ログの `[tc.nfc.tx]` は容量、encoding、チャンク、再送数、DATA時間、
  相手選択完了から送信完了までの時間です。検出前の時間・電子ペーパー描画時間は含みません。
- `[tc.nfc.rx]` は展開・検証・保存の時間と結果。氏名・メール・画像内容はログに出しません。
- SDなし/あり、8 KB程度/大きい写真、旧新の組合せ、途中で離す、再送・重複、保存失敗を確認。
- 本体を旧版へ戻すと交換用画像が無視され、同一世代で異なる画像になって競合する場合があります。
  その場合はスマホで保存世代を進めて名刺を更新してください。競合検証を解除しないでください。

## 名刺帳・削除・SD

- 「メニュー → 名刺帳」。下部の左は名前/最新順、中央は前へ、右は次へ。
  名刺の行をタップすると詳細。最終ページの次は空表示、その次で先頭へ戻ります。
  右上の「戻る」でメニューへ戻ります（読み込み中・空の一覧でも利用可能）。
  大量データは「読み込み中」の間に段階走査します。
- 詳細 → この名刺を削除 → 対象名と接続中の媒体を確認 → 削除する。
  キャンセル可能。完了後は通常操作では戻せません。未接続のSDには削除を予約しません。
- 「設定 → ストレージ」で本体とSDを別々に確認。
  「内訳」は名刺件数、現行名刺の論理サイズ、旧世代/索引等を含むアプリファイル量。
  NVS設定値・FS管理領域・他アプリのファイルはアプリファイル量に含まれません。
- 「保存先：自動（SD優先）」/「本体」を切替。自動でもSDがない、書込不可、空き不足なら内部。
  開始後の保存先変更はせず、不足や抜去はエラーにします。古い名刺は自動削除しません。
- SD画面の「取り外す」後に「取り外し可能」と出てから抜く。
  再開は「再読み込み」、実際の抜き差し、または再起動。取り外し操作はNFC待機を閉じて行います。
- SD上だけの名刺はSDがない間は表示されません。再挿入で一覧へ戻ります。
  内部とSDの同じIDは最新版を表示。片方の削除に失敗したら未完了を通知します。

SDはアプリ専用 `/tc` を使います。認識できないSDを勝手にフォーマットしません。
書込保護・故障・容量不足を完全に区別できない場合は書込不可として内部へ退避する方針です。
RTC保持、電池表示、NFC位置・所要時間、対応SD形式、電源断耐性は実機検証が必要です。

## PaperMono の画面更新

PaperMonoのタッチ座標は、元プロジェクトの座標補正を引き継いで縦横両対応に
しています。M5GFX 0.2.27の座標変換を前提とするため、ライブラリ更新時は
補正の要否を再確認してください。

- PaperMonoは日本語アウトラインフォントを実際の表示サイズで描画します。
  メニュー項目・見出しは32px、設定の補助情報・時刻・フッターは24px。
  名前52〜56px、アカウント32px、メール・コメント28px、名刺アイコン188〜216px。
  名刺帳は88pxアイコンと32pxの名前、24pxのアカウントを表示します。
  StackChanの名刺レイアウトと文字サイズは維持します。
- 起動時のみ高画質の初期更新を行い、通常のメニュー切替は白黒の高速差分更新。
  PaperMonoの初期化途中に行われる重複した画面消去は無効化し、保存済みのホーム内容を用意した後に全画面更新を1回だけ行います。
  その1回の内部では白黒の点滅が発生します。完全な無点滅や起動時間の保証ではありません。
  診断ログ `[tc.boot]` で画面初期化・ストレージ初期化・初回描画・setup全体の所要時間を確認できます。
  写真・名刺・名刺帳は4階調の高速更新を使います。
- ボタンでの選択移動は旧・新の選択枠だけ更新。時計は分が変わったときだけ
  更新し、10回ごとの全画面高画質更新は行いません。
- 写真ホームの時計と電池は写真を挟むため、異なる領域として更新します。
  電池領域は残量が変わった場合だけ追加更新します。
