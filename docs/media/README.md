## READMEの動画を差し替える

GitHubの添付URLを、各READMEの `BEGIN VIDEO` / `END VIDEO` コメントの間に単独の行で配置します。
前後に空行を入れ、画像記法やコードブロックでは囲みません。日英で同じ添付URLを使い、両方のREADMEで再生を確認してください。
動画の添付は[メディア保管用Issue](https://github.com/Corvelis/m5-touch-card/issues/1)で管理しています。
詳細は[GitHubの添付方法](https://docs.github.com/en/get-started/writing-on-github/working-with-advanced-formatting/attaching-files)を参照してください。

## English

Uncut, original-speed hardware recordings with a fixed crop and bilingual captions. Audio and capture metadata are removed.
`devices.jpg` shows both devices; `*-poster.jpg` files are video thumbnails. The phone demo uses an iPhone.
The software's MIT license does not apply to third-party avatars or trademarks visible in the footage.

To replace an embedded video, put its GitHub attachment URL on a separate line between the matching `BEGIN VIDEO` / `END VIDEO` comments.
Leave blank lines around the URL; do not wrap it in image syntax or a code block. Use the same attachment in both READMEs and check playback in each.
The [media issue](https://github.com/Corvelis/m5-touch-card/issues/1) holds the attachments.
