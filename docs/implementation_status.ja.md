## 保存に関する具体的な動作

- 内部に自分の名刺＋アイコン、日時用画像、全画面画像。受信名刺は設定に応じて内部/SD。
- BEGIN前の空き容量スナップショットで受信先を決め、転送中は固定。
  自動では既存コピーの場所によらずSDを優先し、容量不足・不在・書込不可なら内部。
  保存直前に実容量とSD識別子を再確認。転送途中で別媒体へ切り替えて成功にはしません。
- `/tc/<key>.a/.b` にチェックサム付き自己記述レコード、
  `.ia/.ib` に小さな索引。完全なレコードから壊れた索引を再構成。
  検証済み新世代が残った電源断では、応答前でもその世代を回復する場合があります。
- `.del` を先に残して論理削除し、本文・索引を除去後にマーカーを消す。
  起動/一覧走査で未完の削除を再開。接続中の複数コピーだけを削除し、部分失敗は通知。
- SDの識別には `/tc/.volume` のランダム16バイトとマウント世代を使用。
  破損した識別子を勝手に上書きしません。SDのクローンは同一識別になる点には注意。
- 一覧はページ分だけRAMに保持して段階走査。正常レコード検証を伴うので、
  大量の名刺を入れたSDでは集計・ソートに時間がかかります。
- 名前順はUTF-8の辞書順。読み仮名や日本語の五十音変換はありません。
  最新順は受信カウンター順なので、時計未設定でも使えます。
- 初期設定値は内部予約1 MiB / SD予約64 KiB、ペイロード512 KiB、JPEG各256 KiB。
  固定件数での上限ではなく、実空きと新旧世代を保持する作業領域で受信可否を決定。

初期化します。SD全体のフォーマット、旧v1データ自動移行、バックアップUI、
